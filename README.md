# Colortyme content catalog

This static catalog contains one representative animals theme. Serve this directory as the document root of any reachable HTTP(S) endpoint and set the app build property `catalogUrl` to the served `catalog.json` URL. The catalog references `themes/animals.json`, which references the page image at `themes/animals/donkey.png`.
